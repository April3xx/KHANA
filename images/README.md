# images

Put your photos here, then point the site at them.

For each honey-toned placeholder in the HTML, replace the
`<image-slot ...></image-slot>` tag with a real image, e.g.:

    <img src="images/phayao-dawn.jpg" alt="Phayao at dawn" />

Slots to fill (by id, found in the HTML):
- index.html → hero-phayao, founder
- story.html → story-founder, story-phayao
- buy.html   → buy-jar, buy-t1, buy-t2, buy-t3

Suggested: large hero images ~1600px wide, product shots ~1000px square,
saved as optimized .jpg or .webp.
